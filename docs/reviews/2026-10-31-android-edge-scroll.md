# Android page scrolling

Android windows already enable edge-to-edge system bars. The theme forced inline navigation titles, whose default scroll behavior was pinned. All navigation stacks now use the same enter-always scroll behavior: scrolling upward removes the title/actions from the viewport, downward scrolling restores them. System inset protection and the floating tab bar remain. Each expanded Browse/Data pane retains its own navigation state and scrolling connection.

Browse had a second nested scrolling surface: a LazyVGrid inside the page ScrollView. On Android the grid consumed scrolling while the surrounding Health Categories heading stayed in place. Category tiles now use two-column non-scrolling rows within the page scroll view; search results use that same scroll view. The search control remains above the scrollable content. iOS retains its native navigation/search implementation.

Regression coverage: `tests/android/ui_smoke.py edge-scroll` checks folded and expanded viewports, title removal, fixed search, category heading removal, category/detail navigation, and tab return retaining the selected detail. The old build failed the search-position assertion. The intermediate navigation-only change failed the category-heading assertion, reproducing the separate grid issue.

Validation: Docker Android unit/lint/package checks and the combined image build passed. The final emulator regression passed folded and expanded scrolling, independent left/right panes, retained detail on tab return, and all five tab navigation bars hiding/restoring. The emulator fixture used 20 categories and 222 entries. iOS simulator and unsigned device builds passed, as did 56 shared core tests. Android Build 33 was installed over the USB-connected phone with its application data retained; a subsequent controlled expanded-screen swipe verified that scrolling the left category pane did not move or replace the right HRV detail pane. Folded interaction checks were performed on the emulator. NAS now serves image `edge-scroll-20261031`; its status endpoint is healthy.
