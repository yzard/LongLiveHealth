# Blood Work categorization and rescanned report coverage

The shared iOS/Android Browse classifier now assigns laboratory analytes to Blood Work before applying organ-related name rules. ApoB, LDL/HDL cholesterol, triglycerides, lipoprotein(a), hs-CRP, homocysteine, troponin and natriuretic peptides therefore stay with laboratory tests. Dietary cholesterol remains Nutrition; heart rate/HRV and explicitly identified clinical ECG measurements remain Heart.

Read-only review of the current confirmed Function Health report found 126 rows, 118 distinct name/unit combinations and 117 distinct metric identities. All 117 metric entries already existed in the live 150-entry Browse catalog. However, one Function Health row, Globulin with unit `g/dL (calc)`, could not resolve to its metric. Its Browse entry existed because of other source records, masking the missing report contribution. The closed unit-alias list now recognizes this calculated-unit spelling as g/dL without changing stored originals or globally lowercasing SI units. No rescan or database rewrite is required for existing confirmed rows.

The regression fixture contains only marker labels and units, with no patient identifiers, values or collection dates. Its integration test uses synthetic values/dates, confirms all rows, and asserts every metric appears in Browse. It also checks that the calculated Globulin result appears in both plotted points and historical records with canonical g/dL units. Shared category tests cover cardiac laboratory analytes and non-laboratory cardiac measurements. Private read-only audit evidence is under ignored `build/ocr/browse-audit/`.
